# ELOCHILL

Подтверждение результатов StandChillow: игрок отправляет скриншот матча, система имитирует проверку и начисляет Эло. APK собирается через GitHub Actions.

## Что внутри

- `www/` — веб-приложение (HTML/CSS/JS), обёрнутое в Android WebView через Capacitor.
- `supabase/schema.sql` — база, триггер уровня и серверная логика.
- `.github/workflows/build-apk.yml` — сборка APK в GitHub Actions.

## Настройка Supabase (один раз)

1. Откройте проект Supabase → **SQL Editor** → **New query**.
2. Вставьте весь `supabase/schema.sql` и нажмите **Run**.
3. Готово. URL и publishable-ключ уже прописаны в `www/app.js`.

## Сборка APK

1. Создайте GitHub-репозиторий и залейте туда содержимое этой папки.
2. Workflow `Build APK` запустится сам при push в `main`/`master`.
3. APK лежит в **Actions → последний run → Artifacts → ELOCHILL-APK**.
4. Чтобы получить ссылку на установку: создайте тег `v1.0` и запушьте его — APK прикрепится к Release.

Ручной запуск: **Actions → Build APK → Run workflow**.

## Анти-чит

Вся проверка живёт на сервере, клиент не может подделать результат:

- Эло и уровень меняются только в `SECURITY DEFINER` функции `submit_result`. Прямые `INSERT/UPDATE` таблицы у anon/authenticated отозваны — доступен только `SELECT`.
- Решение «принять/отклонить» генерируется на сервере (`random() < 0.8`). Клиент не знает исход проверки до ответа.
- Лимиты enforcing-ся в базе: 1 проверка в 3 минуты и максимум 10 в день, с сбросом счётчика по UTC.
- Строка профиля блокируется `FOR UPDATE`, поэтому параллельные запросы не обходят лимит.
- Исход матча валидируется (`win`/`lose`), ник — по длине и уникальности.
- Каждая проверка пишется в таблицу `submissions` для аудита (клиенту недоступна).
- Уровень пересчитывается триггером из Эло, а не берётся от клиента.

## Офлайн

- Онлайн: вход, проверки, таблица лидеров — через сервер.
- Офлайн: доступен просмотр последней таблицы лидеров и профиля из `localStorage`; кнопка отправки заблокирована.
- Индикатор соединения в шапке.

## Правила Эло

Победа `+50`, поражение `−10`. Уровни: 1:0, 2:200, 3:500, 4:900, 5:1400, 6:1800, 7:2100, 8:2300, 9:2500, 10:3000, 11:3800, 12:4700, 13:5700, 14:6800, 15:8000.
